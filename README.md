# serohubmap

开源项目 [servohub](https://github.com/magic-alt/servohub)（伺服电机驱动器固件）的项目地图：把 1029 个文件分成 18 个部分，用图说明每个部分是做什么的、怎么工作、指令怎样一路变成电机转动。

- `index.html`：地图页面，单个文件，下载后用浏览器打开即可。
- `parts.md`：地图的来源，一份用平常话写的部件清单和流程图。

## 看之前要知道的

- 地图按 servohub 在 2026-11-12 的最新提交（`94fc13d`）绘制，之后的改动没有反映。
- servohub 几乎全是 C 语言，部件之间的箭头是读代码后画的，不是工具量出来的，所以主线上的箭头都是虚线。
- 18 个部分里有 10 个画了流程图，其余只有名字、说明和文件归属。
- 部件的名字和说明是读代码后起的，不是 servohub 作者写的，可能有不准确的地方。
- 这里只有地图，不包含 servohub 的源代码。
